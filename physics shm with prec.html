Laboratory Precautions

  • Small amplitude ≤ 15° — keeps the small-angle approximation (and the SHM formula) valid.
  • Time 20+ oscillations — reduces human reaction-time error to negligible levels.
  • Measure L from the pivot to the centre of the bob — not to the top of the string.
  • Time at equilibrium — the bob is fastest there, so start/stop the timer when it passes the mid-point.
  • Swing in a single plane — no conical or elliptical motion, which breaks SHM.
  • Firmly clamp the retort stand — an unstable stand can topple and cause injury.
  • Same pivot, same string, same bob for every trial — only L should change.
  • Repeat each length 3× and average — random errors cancel out.
